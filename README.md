# HARDCORE: Legend of Onion Head

Onion Head, a small robot core, climbs into the bodies of the robots it beats and fights its way through three levels.

- Play: `npm run build`, then open `dist/hardcore.html` in a browser.
- Test: `npm install` once, then `npm test`.
- Design: `gamedesign.md`. History: `CHANGELOG.md`. Earlier builds: `versions/`.
- Moving this project into Claude Code: see `העברה.md` (Hebrew).
